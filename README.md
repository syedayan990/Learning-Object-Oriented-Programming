# C++ Object-Oriented Programming (OOP)

A collection of C++ programs and practical examples covering the core concepts of Object-Oriented Programming (OOP).

This repository contains my learning and practice implementations of important OOP concepts in C++, including classes and objects, abstraction, encapsulation, inheritance, and polymorphism.

---

## 📚 Topics Covered

### 🔹 Class & Object
- Classes
- Objects
- Data Members
- Member Functions
- Creating and Using Objects

### 🔹 Encapsulation
- Data Hiding
- Access Specifiers
- `private`
- `public`
- `protected`
- Getters and Setters

### 🔹 Abstraction
- Abstract Classes
- Pure Virtual Functions
- Interfaces
- Hiding Implementation Details

### 🔹 Inheritance
- Base Class
- Derived Class
- Single Inheritance
- Multilevel Inheritance
- Hierarchical Inheritance
- Multiple Inheritance
- Hybrid Inheritance

### 🔹 Polymorphism

#### Compile-Time Polymorphism
- Function Overloading
- Operator Overloading

#### Run-Time Polymorphism
- Function Overriding
- Virtual Functions
- Base Class Pointers
- `final` Keyword
